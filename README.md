# Build Camp

Learn to build real things with AI by building real things with AI.

This is a starter kit for new builders using [Claude Code](https://docs.claude.com/en/docs/claude-code/overview).
It turns Claude into a coach: it interviews you, suggests projects that fit what you're
into, and teaches you the habits that make AI tools powerful rather than just handing
you finished code.

## Start here
1. Do **Mission 0** in [claude.ai](https://claude.ai) first. You don't have to install
   anything.
2. When you're ready for Mission 1, install Claude Code:
   https://docs.claude.com/en/docs/claude-code/overview
3. Get your own copy: click **Use this template** at the top of this page (or clone it).
4. Open a terminal in your copy, run `claude`, and type:
   *"Read PROGRESS.md and tell me where we are."*
   The first time, Claude will interview you before you build anything.

## What's inside
- [`CLAUDE.md`](CLAUDE.md): the coach's rules. Read it; you'll write your own in Mission 4.
- [`MISSIONS.md`](MISSIONS.md): the 8-step ladder, one shipped project and one habit each.
- [`PROGRESS.md`](PROGRESS.md): your profile, your projects, your log.
