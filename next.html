Hard mode: the real tools.

So far the AI has built things in a chat window. Now it gets hands: it makes files on your computer, runs them, and fixes what breaks. You'll need a laptop, a $20-a-month Claude plan, and about half an hour for setup and your first build.

STEP 1

Get Claude Code

Follow the install step for your computer. It needs a paid Claude plan; the cheapest is Pro, at $20 a month. The free plan doesn't include it.

Install Claude Code →
STEP 2

Download the kit

It's a small folder that turns Claude into a coach. Unzip it somewhere you'll find it again. You'll get a folder called build-camp-master.

Download the kit →
STEP 3

Say hello

Open a terminal in the build-camp-master folder, type claude and press Enter. Then say:

Let's start.

Mac: right-click the folder → New Terminal at Folder.
Windows 11: right-click the folder → Open in Terminal.
Windows 10: open the folder, hold Shift, right-click an empty spot → Open PowerShell window here.
Chromebook: in Settings, search for "Linux" and turn on the Linux development environment. Use the Terminal app it adds, and the Linux install steps.

What happens next: it asks what you're into, builds your first thing with you on the spot, and lines up the rest around you:

  • MISSION 1 Your own page, live on the internet if you choose
  • MISSION 3 A Discord bot or app your friends actually use
  • MISSION 5 Something that runs by itself every day
  • MISSION 7 Tools for real places: a house, a shop, a ranch

There are eight missions in all; the ones between these teach you to test, plan and get a second opinion.

Stuck on setup? Paste the error into Claude and ask what it means. That isn't cheating; it's the job.

School or work laptop? It may block the install. If it does, you haven't lost anything: keep building in the chat, where everything still works.
