# Build Camp

Learn to build real things with AI by building real things with AI.

## Start here
1. Do **Mission 0** in [claude.ai](https://claude.ai) first. No install needed.
2. When you're ready for Mission 1, install Claude Code:
   https://docs.claude.com/en/docs/claude-code/overview
3. Copy this folder, open a terminal in it, run `claude`, and type:
   *"Read PROGRESS.md and tell me where we are."*

The `CLAUDE.md` file tells Claude to coach you rather than just do it for you. Read it;
you'll write your own version in Mission 4.

See [MISSIONS.md](MISSIONS.md) for the ladder.
